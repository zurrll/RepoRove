- `device-final.txt`：5 项新功能设备用例与 2 项浏览器登录回归集中通过，0 失败。包含真实系统通知及 PendingIntent 路由；仓库数据来自确定性本地 HTTP 服务。
- `r8-trending-final.txt`：最终已签名 R8 APK 使用真实公开 GitHub Trending 完成各时间范围、语言、完整列表、精选，以及实际系统后台任务、通知栏点击与关闭清理。网络错误重试为 0。
- `r8-baseline-final.txt`：同一 APK 的真实浏览、仓库头部、发布详情、组织、生产离线保存、实际关闭网络后的 README / 代码 / 文件树、删除与版本历史回归通过，网络错误重试为 0。
- `r8-trending-selector-first.txt`：首轮线上失败，输入框文字 Python 被通用“按钮”匹配器命中，页面停在语言弹窗。仅把查询改成部分词 `pytho`，没有放宽目标语言、完整榜单或通知断言，使用同一产品 APK 重跑通过。
- `ci-final.json`、`ci-validation.json`：分别保存冻结产品提交与测试选择器修正提交的远端 CI 成功结果和公开链接。
- `package-manifest.json`、`apk-signature.txt`、`apk-alignment.txt`：APK 来源、哈希、大小、版本、同签名连续性及对齐检查。产品 APK 没有因测试选择器或后续文档变更重新生成。
- `publication-final.json`：用户授权后的公开 Release、源码标签、四项附件的远端大小 / SHA-256，以及匿名实际下载 APK 与验收包相同的校验结果。README 和新增截图也已检查公开访问。

第一轮因模拟器遗留代理 127.0.0.1:7890 而中断，清除代理后取得可复现结果。随后集中检查曾出现 3 项失败：精选返回热榜错误恢复子页面、语言选择器匹配多个 Python 节点、Android 15 的 AppOps 模拟没有实际撤销通知权限。分别修复导航、使用明确选择器标识、在测试进程外撤销运行时通知权限后，最终 7 项集中通过。没有放宽完整榜单或通知去重断言。

运行设备用例前在自有 API 35 模拟器清除 App 数据与旧代理，并在测试进程外执行 `pm revoke app.reporove android.permission.POST_NOTIFICATIONS`。用例按固定顺序先检查拒绝权限，再主动授权测试真实系统通知；不要在正在运行的测试进程中撤销权限。

后台流程在本机白天以 ADB 强制触发真实已持久化的 JobScheduler 任务，App 已退到后台；它证明任务、网络、实际通知、点击与去重链路，不保证系统自然调度、准点通知或 ColorOS 后台到达率。一加手机体验、完整真实账号授权均等待用户验收。完整实现与交付见 [0.6.2 记录](../../../0.6.2热榜与每日发现.md)。
