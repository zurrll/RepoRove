第一轮因模拟器遗留代理 127.0.0.1:7890 而中断，清除代理后取得可复现结果。随后集中检查曾出现 3 项失败：精选返回热榜错误恢复子页面、语言选择器匹配多个 Python 节点、Android 15 的 AppOps 模拟没有实际撤销通知权限。分别修复导航、使用明确选择器标识、在测试进程外撤销运行时通知权限后，最终 7 项集中通过。没有放宽完整榜单或通知去重断言。

运行设备用例前在自有 API 35 模拟器清除 App 数据与旧代理，并在测试进程外执行 `pm revoke app.reporove android.permission.POST_NOTIFICATIONS`。用例按固定顺序先检查拒绝权限，再主动授权测试真实系统通知；不要在正在运行的测试进程中撤销权限。
