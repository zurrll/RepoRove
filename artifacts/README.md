# 验收材料与本地产物

源码仓库保留各轮已引用的测试日志、报告、包校验清单和截图，供回看实现证据。报告中原工作区的绝对路径属于当次运行信息，不是构建依赖。

APK、AAB、签名文件、R8 mapping、源码快照、临时失败诊断和本机工具不上传到源码仓库。原工作区仍保留这些文件；克隆仓库后可按 CONTRIBUTING 构建。校验清单描述对应预览包；0.6.0 批次经用户授权将各版 APK 发布到 GitHub Releases，APK 本体仍不写入 Git。

当前最新验收见 [0.6.0 阅读修复与公开发布](../0.6.0阅读修复与公开发布.md)。旧版本记录保留原有时间与验证范围，不能用于声称新版本或目标手机已验证。

0.5.0 的日志和生成 HTML 已清理行尾空白与多余文件末尾空行，测试结果和报告内容不变。
