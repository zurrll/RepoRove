# 验收材料与本地产物

源码仓库保留各轮已引用的测试日志、报告、包校验清单和截图，供回看实现证据。报告中原工作区的绝对路径属于当次运行信息，不是构建依赖。

APK、AAB、签名文件、R8 mapping、源码快照、临时失败诊断和本机工具不上传到源码仓库。原工作区仍保留这些文件；克隆仓库后可按主 README 构建。校验清单描述当次本地预览包，不表示对应 APK 已随源码上传。

当前最新验收见 [0.5.0 离线阅读与翻译](../0.5.0离线阅读与翻译实现.md)。旧版本记录保留原有时间与验证范围，不能用于声称新版本或目标手机已验证。

0.5.0 的日志和生成 HTML 已清理行尾空白与多余文件末尾空行，测试结果和报告内容不变。
