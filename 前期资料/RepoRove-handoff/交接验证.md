## 验证边界

- 本轮浏览器工具仅允许 HTTP/HTTPS 地址，因此通过本机服务器验证单文件运行；直接双击 `file://` 的行为未实测。受限环境按交接 README 的本机服务器方式打开。
- 所有内容都是虚构数据。本次没有验证 GitHub 登录、远端 API 写入、真实 CI、真实下载或 Android APK。
- 检查覆盖交接后的重点路径，不代表每个演示弹窗已实现正式业务逻辑。功能完整度以开发说明第 2 节为准。
- 源码安装验证产生的依赖和构建缓存不随包交付；接手者按 `prototype/README.md` 安装和构建。
