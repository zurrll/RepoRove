# 隐私说明

适用当前源码（0.6.3）。RepoRove 没有账号数据收集后台、广告或分析统计 SDK。

- 项目和账号请求直接访问 GitHub；文档外部图片可能访问原图片主机。浏览器授权在 GitHub 官方网页进行。
- GitHub 凭据与翻译 Key 分开加密保存在手机上，由 Android Keystore 保护；不写入日志，不发送给项目作者。
- 翻译由你主动开启，所需文档段落、受保护的行内内容占位符及仓库 / 文件名称发送到你配置的服务。源码不翻译；私有文档另行确认。服务会按自己的规则处理内容和计费，GitHub 凭据不会发送给它。
- 收藏、设置、缓存、阅读记录与离线快照存于本机，不启用云备份或设备迁移。换账号 / 凭据时清理账号缓存、私有快照与译文缓存；公开离线仓库保留。翻译配置可在设置中删除。
- 热榜匿名读取 GitHub 公开页面，兴趣精选在本机生成。提醒默认关闭，开启后才申请通知权限并安排系统任务；到达时间受系统限制。
- 剪贴板仅在前台有焦点时检查，确认后才打开链接，可关闭；去重保存摘要。下载由系统服务管理，删除限于 App 记录的文件，不申请所有文件访问权限。

联网、前台同步和通知权限用于对应功能；打开 APK 时，安装来源和实际安装由你在系统页面确认。主动填写问卷或提交 Issue 时，请避免公开密钥和私人信息。

问题请提交 [Issues](https://github.com/zurrll/RepoRove/issues)。
