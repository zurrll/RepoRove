# RepoRove 隐私说明

适用版本：0.6.1。RepoRove 是独立的开源 GitHub 客户端，项目作者没有运营用于收集账号数据的后端。

- App 向 GitHub API 请求你打开的项目、搜索结果和账号内容；公开头像与 README 中的外部图片可能从其原始图片主机加载。
- GitHub 访问令牌在本机用 Android Keystore 保护的加密设置保存，仅在受约束的 GitHub API 请求中发送。浏览器登录启用后，设备授权及登录续期直接访问 GitHub 官方授权服务，刷新令牌同样加密保存在本机。令牌不写入日志，不发送给项目作者；GitHub 密码只在官方网页输入。
- 稍后看、跟踪、设置、最近阅读、响应缓存和离线仓库存于本机。退出或换凭据会清理对应私有快照与账号缓存；公开离线快照可继续保留。App 数据不启用云备份或设备迁移。
- 剪贴板识别只在前台窗口有焦点时检查，可关闭。询问后由你决定是否打开；去重只保存已处理链接的摘要，不保存原文。
- 下载文件由 Android 系统下载服务管理；App 内离线源码通过前台保存服务下载，进度可见。删除只针对 App 记录的文件，不申请所有文件访问权限。
- 当前没有 AI 翻译服务，不会将文档提交给模型服务；升级会清理旧翻译配置、独立密钥与译文缓存。
- 当前没有广告或分析统计 SDK。向 GitHub 提交 Issue 或分享截图属于你主动公开的内容，请遮盖令牌和私人信息。

应用申请联网、网络状态及前台数据同步服务权限，用于 GitHub 访问与离线保存。0.6.1 打开下载的 APK 时可请求进入系统安装流程，允许安装来源及实际安装由你在系统页面决定。系统安装器、剪贴板与下载服务的行为也遵循你设备上的 Android 设置。

问题可通过 [GitHub Issues](https://github.com/zurrll/RepoRove/issues) 反馈。
