# 使用指南

适用当前源码 0.6.3；已发布 APK 及各版变化以 [Releases](https://github.com/zurrll/RepoRove/releases) 为准。

## 安装与登录

下载 APK 后交给系统安装器安装；同签名预览版可覆盖更新。卸载会清除 App 内设置、收藏和离线内容。

浏览公开项目无需登录。需要账号功能时：打开“我的”→“通过浏览器登录”→复制授权码并在 GitHub 官方网页确认→返回 App。私有仓库权限按需开启，组织可能另需 SSO 或管理员批准。

也可展开“使用访问令牌登录”。Classic PAT 的 Star、收件箱、组织分别需要 `public_repo`、`notifications`、`read:org`，私有仓库需要 `repo`。当前支持单账号，退出不会删除 GitHub 上的内容。

## 发现与热榜

“为你”按兴趣推荐，“探索”提供 GitHub 主题与合集，“仓库排行”按总 Star / Fork 等指标排序。“热榜”是完整 GitHub Trending，支持日 / 周 / 月与语言筛选，不受兴趣和已读状态删减。

“今日精选”另外按兴趣挑选少量项目；提醒默认关闭，可在铃铛入口开启。每天最多一条，后台到达受系统省电限制。热榜也能设为底部入口或启动页。

搜索支持类型与可视化筛选，也接受 GitHub 查询语法；部分能力需登录。

## 文档与代码

Markdown 默认阅读模式，文件操作菜单可切换源码。点击阅读栏文件名查看位置、版本和文件树；快速打开查最近文件和文件名，在线范围为已加载目录，离线为已保存源码。

章节链接原地定位，跨文件链接返回时回到来源位置。代码支持高亮、换行、完整文件查找和跳行；“复制整个文件”不受显示分段限制，长按复制则只取选区。

### 段落双语

在“设置 → 段落双语”填写 API Key。可用千问翻译，或兼容 Chat Completions 的服务；其他地域 / 业务空间请展开接口设置，填写完整 HTTPS 地址与相应 Key。

打开项目介绍或文档上的翻译开关，译文跟随原段出现。只处理阅读位置附近的内容，已完成段落可缓存复用；费用由服务收取。源码与注释不翻译，文档中的代码和原链接保留。失败可点对应段落重试；私有文档发送前单独确认。

当前目标为简体中文；按需翻译不等于全文离线保存。关闭双语可随时恢复原文，设置中可删除配置和译文缓存。

## 收藏、跟踪与离线

- **稍后看**：待阅读清单，在项目库中找回。
- **Star**：同步到 GitHub 账号的收藏。
- **App 内跟踪**：在动态页查看项目公开活动，独立于 GitHub Watch。
- **离线保存**：仓库“保存到 App → 离线保存资料 / 源码”，完成后在项目库“离线与最近阅读”打开。

离线资料含项目简介、语言与 README，源码为固定提交快照；不含 Git 历史、子模块和 LFS 实体。未保存的外部图片或文件可能不可用，二进制不预览，单个文本上限 1 MiB。临时缓存容量有限，需要可靠断网阅读时请主动保存。

## 下载与外观

发布版本先显示说明，再选择附件或源码归档。项目库“下载”可打开和删除文件，位置为 `Downloads/RepoRove`。APK 交给系统安装器，其他文件需要手机上有对应应用；私有附件当前需经 GitHub 网页下载。

设置提供主题、字号、密度、导航、启动页与全仓库共用栏目。剪贴板链接识别可关闭，只在前台检查并由你确认是否打开。
