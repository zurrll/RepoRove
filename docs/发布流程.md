# 发布预览版

1. 集中完成已授权批次，更新版本号、App 内更新记录与必要说明。
2. 通过单元测试、Debug / Release lint 和相关设备回归；验证最终签名 R8 包。
3. 校验版本、同签名升级、zipalign 与 SHA-256，先交付用户手机验收。
4. 用户确认发布且对应源码 CI 通过后，为完整源码打版本标签，创建预览 Release。
5. 上传同一验收 APK、SHA256SUMS、包信息和第三方许可；实际下载校验远端附件。

不将密钥、mapping 或过程报告提交到仓库，不用重建包替代已验收包。历史 Release 保持原样；0.1.0–0.3.0 标签仅归档当时 APK，不含完整可重建源码。
