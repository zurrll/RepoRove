# RepoRove

原生 Android GitHub 客户端。默认清晰阅读，纸感可选，先把发现、阅读、收藏、跟踪和版本下载做好。初期重点验证一加 Ace 5 / ColorOS 16，最低 Android 10（API 29）。

正式工程在 `app/`，前期网页原型和交接资料保留在 `前期资料/`。

当前为私有开发仓库，源码版本 0.4.1。文档入口见 [文档索引](./文档索引.md)，本阶段安排见 [试用与发布计划](./试用与发布计划.md)，开发约束见 [CONTRIBUTING](./CONTRIBUTING.md)。体验反馈先记录到 [待处理清单](./待处理体验反馈.md)，收到批次实施指令后集中修改和出包。公开开源、源码许可证和安装包发布另行确定。

## 当前能力

- 真实 GitHub 数据：为你 / 探索 / 热门，官方主题与合集目录，以及仓库 / 代码 / Issue / PR / 用户与组织 / 主题 / 提交 / 讨论的可视化分类搜索。
- 仓库概览、GitHub GFM README、站内个人/组织主页与作者入口、分支与目录、文本文件、Issue/PR 正文及评论、PR 差异、提交、Release、Actions Job/步骤和公开 Wiki。
- 仓库信息随上滑收起，栏目与仓库名保持可用；表格、代码块在自身区域左右滑动，宽表格按实际溢出提示，长单元格换行并保留对齐。
- 单账号登录、真实 Star、我的仓库、我的组织、GitHub 收件箱及已读/完成操作；访问权限由 GitHub 凭据决定。
- 本机稍后看和 App 内跟踪、跟踪仓库的近期公开活动、GitHub 关注动态；通知和事件按具体对象跳转，CI 读取真实关联运行。
- 版本说明优先，顶部可跳到附件及源码 ZIP/TAR；公开文件使用官方附件/归档 API 与系统下载管理器，保存准确位置，确认磁盘文件删除后才清理记录；私有附件提供 GitHub 网页入口。
- 底部导航及启动页、仓库栏目及概览模块可选择和排序；未常驻栏目进入“更多”，所有仓库共用布局。
- 清晰/纸感主题分别支持浅色/深色/跟随系统、紧凑密度、阅读字号、按账号隔离的内容缓存和错误/离线提示。

“热门”使用 Star 排序。“为你”根据明确选择的兴趣生成，可选择启用 Star 主题推断，兼顾关注度和维护情况，少量探索新项目；不冒充官方 Explore 或 Trending 榜单。目录外主题也可输入并保存。稍后看在项目库，持续跟踪管理在动态页。主页置顶默认折叠，自己的 Star 留在项目库。评论提交、PR 审核操作、Actions 操作、多账号、AI 翻译及后台更新推送留待后续。

## 构建

需要 JDK 17、Android SDK 平台 36、Build Tools 35.0.0。Gradle Wrapper 随工程保留并带发行包 SHA-256 校验。

配置 `JAVA_HOME` 与 `ANDROID_HOME`，并在未提交的 `local.properties` 中填写 `sdk.dir=/你的/Android/sdk`；也可以用 Android Studio 打开本目录。

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug :app:lintRelease :app:assembleRelease
```

Debug APK：`app/build/outputs/apk/debug/app-debug.apk`。Release 启用 R8，默认生成未签名 APK；公开发布必须使用发布主体自己持有的签名密钥。本工作区的 `.tools/` 开发环境忽略版本控制，工程没有依赖这些绝对路径。

## 登录

当前安装测试版可以用 GitHub classic PAT 登录。Star 需要 `public_repo`，收件箱需要 `notifications`；私有仓库需要 `repo`；“我的组织”需要 `read:org` 及组织允许的访问权限。Projects 的 GraphQL 查询需要 `read:project`。公开浏览不要求登录，代码搜索等接口受 GitHub 自身的认证限制。

浏览器登录的设备授权流程已实现。正式发布前需注册自己的 GitHub OAuth App 并启用 Device Flow，再构建：

```sh
./gradlew :app:assembleDebug -PgithubOAuthClientId=你的客户端ID
```

App 不包含客户端密钥，基础功能不需要服务端。不要提交 PAT、发布密钥或密码。OAuth 与通知权限的真实账号兼容性仍需在发布账号上验收。

## 继续运行网页原型

在项目主目录执行：

```sh
cd 前期资料
npm run dev
```

首次安装依赖时，在 `前期资料/` 执行 `npm ci`。浏览器访问 `http://localhost:5173`，以终端显示的实际地址为准。

网页原型仍使用演示数据；Android 工程使用真实 GitHub API。
